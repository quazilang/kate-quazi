# Quazi for Kate, KWrite, and KDevelop

Install `syntax/quazi.xml` in Kate's syntax-definition directory and merge the
`servers.quazi` entry from `lspclient/quazi.json` into LSP client's settings.
It launches `qz lsp`. The canonical [LSP contract](https://github.com/quazilang/quazistrap/blob/main/docs/tooling/lsp.md) is authoritative.
